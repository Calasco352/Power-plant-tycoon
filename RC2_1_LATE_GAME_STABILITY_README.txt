POWER PLANT TYCOON — RC2.1 LATE-GAME STABILITY + INFINITE EMPIRE PROGRESSION

Built from Monetization RC2.

KEY FIXES
- Rebalanced long-term multipliers so prestige, regions, research, mega projects and empire bonuses no longer multiply into runaway billions-of-percent efficiency.
- Huge power sales now award logarithmic/capped company XP instead of XP directly proportional to stored energy.
- Non-linear company XP requirements and a hard per-action XP safety cap prevent giant single-sale level jumps.
- Sale multipliers are sanity-limited to prevent event/contract/market stacking from producing corrupted values.
- Save migration repairs non-finite/corrupted late-game values while preserving the player's actual progression where possible.
- Corporate efficiency upgrades are capped at Level 25 and staff specializations at Level 50.

NEW LONG GAME
- Prestige now requires cash earned during the CURRENT prestige run, not only lifetime cash.
- Prestige awards permanent Grid Credits.
- Grid Credits fund four Legacy Grid upgrade trees: production, sale value, reliability/wear, and offline efficiency.
- Prestige milestones at 10 / 25 / 50 / 100 / 250 / 500 / 1000 award bonus Grid Credits.
- Prestige production bonus now uses diminishing returns instead of an endlessly linear multiplier.
- Empire Level bonuses also use diminishing returns, but Empire Levels continue indefinitely.
- Milestones now extend through Qi, Sx, Sp, Oc, No and Dc cash tiers.
- Electrical display adds RWh/QWh and RW/QW for extreme late-game values.

SAVE COMPATIBILITY
- Existing PPT_V5 saves are preserved.
- Existing late-game saves automatically receive the RC2.1 stability migration.
- Existing cash on an older save is used as the initial current-run prestige progress so advanced players are not forced to restart immediately.
